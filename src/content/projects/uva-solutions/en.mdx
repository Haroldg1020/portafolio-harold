## The challenge

Sharpen my problem-solving skills: read a statement, find the right algorithm and write a correct, efficient solution that passes every test case on the judge.

## The solution

A repository with my solutions to problems from the [UVa Online Judge](https://onlinejudge.org), written in C and C++. Each file is named after the problem number it solves.

## What I learned

Careful input/output handling, complexity analysis and the use of stacks, queues and maps to solve problems under time limits.
